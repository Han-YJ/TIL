# 국제 전화 다이얼코드는 여러 나라가 같이 쓴다

- `+1` 은 미국·캐나다와 카리브해 여러 나라·지역(자메이카, 바하마, 도미니카공화국, 푸에르토리코 등)이 함께 쓴다. 북미 번호 계획(NANP) 하나를 공유해서 25곳 안팎이다
- `+7` 은 러시아와 카자흐스탄이 같이 쓴다
- 그래서 `+1 604-555-0100` 만 보고는 어느 나라인지 알 수 없다

이런 경우가 생긴다:

- 폼이 전화번호를 「+다이얼코드 번호」 문자열 하나로 들고 있다가 저장할 때 다이얼코드로 국가를 되찾으면, 대표 국가(보통 미국·러시아)로 바뀐다. 캐나다 번호를 고치기만 해도 미국으로 저장된다
- 같은 다이얼코드 안에서 국가를 바꿔도(미국 → 캐나다) 문자열이 그대로라 변경으로 잡히지 않는다

국가는 다이얼코드가 아니라 ISO 국가 코드(`CA`, `US`)로 들고 다니면 된다.
