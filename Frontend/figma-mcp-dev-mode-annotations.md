# Figma MCP로 Dev Mode 주석 읽기 — 하위 노드를 직접 열어야 보인다

디자이너가 Dev Mode에 달아 둔 주석(「동작」·「이동」 같은 분류 뱃지 + 설명)은 Figma MCP `get_design_context` 응답 코드에 **`data--annotations="…"` 속성**으로 붙어 온다.

```tsx
<div data-node-id="3015:526386" data--annotations="카드는 늘 1개만 켜짐 · 켜진 카드 재클릭 = 전체" data-name="Stack">
```

## 안 보이는 경우

| 경우 | 결과 |
|---|---|
| 화면 전체처럼 큰 프레임 조회 | 응답이 구조만 담긴 sparse 메타데이터로 바뀌고 주석이 빠진다 |
| `get_screenshot` | 화면만 그려지고 주석은 안 그려진다 |
| 분류 뱃지(「동작」·「이동」) | 본문만 오고 분류는 빠진다 |

## 교훈

- 화면을 통째로 한 번 조회하고 「주석 없음」으로 판단하면 동작 명세를 놓친다. sparse 응답이 오면 **하위 노드를 나눠 직접 조회**하고 `data--annotations` 를 모은다.
- 분류는 빠지므로 동작인지 이동인지는 본문 문장으로 판단한다.
